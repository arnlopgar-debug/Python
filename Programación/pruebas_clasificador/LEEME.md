# Escenarios de prueba realistas (datos ficticios)

Este corpus contiene 328 archivos creados para imitar flujos cotidianos de finanzas, móvil, oficina, desarrollo, entregas de proyecto y copias compartidas. No contiene datos personales ni documentos descargados de Internet.

- Incluye PDF, DOCX, XLSX, PPTX, CSV, SQLite, JSON, código, imágenes, audio, vídeo y ZIP.
- Incluye duplicados exactos, 10 extensiones engañosas deliberadas y archivos ambiguos para probar la abstención.
- Algunos documentos son fixtures mínimos válidos para detectar formato; no todos son documentos de producción completos.

## Prueba segura

Ejecuta el script inteligente y elige `1` (asistente completo). Introduce la ruta de esta carpeta. Revisa el análisis y la vista previa; responde `n` para cancelar cualquier acción y conservar todas las muestras. El modelo tiene 23 etiquetas; las predicciones de subcategoría son sugerencias y los cambios requieren aprobación.
